# Reefer Container Handling Procedure

*Synthetic/demo document created for a portfolio project. This is not a real operational
manual and does not represent the procedures of any actual company or terminal.*

## 1. Purpose and Scope

This procedure covers the handling of refrigerated ("reefer") containers from gate-in
through vessel loading or gate-out, including temperature monitoring, power
connection, and response to temperature deviations or equipment failure. It applies to
all terminal staff assigned to reefer yard operations.

## 2. Gate-In Requirements

At gate-in, the operator records the set-point temperature, cargo type, and any
special handling instructions (such as controlled atmosphere requirements) from the
shipping documentation. The reefer unit's display is checked to confirm it matches the
declared set-point before the container is accepted. Any discrepancy between the
declared and displayed set-point must be resolved with the shipping line before gate-in
is completed.

## 3. Power Connection and Placement

Reefer containers must be connected to a powered rack within thirty minutes of
placement in the yard. Yard planners prioritize reefer placement to minimize the gap
between gate-in and power connection. Each reefer connection is logged in the terminal
operating system with the rack number, connection timestamp, and confirmed set-point.
Containers that cannot be connected within the thirty-minute window must be flagged to
the duty operations manager and monitored manually until connected.

## 4. Temperature Monitoring

Connected reefer containers are monitored continuously through the terminal's remote
monitoring system, which polls each unit every fifteen minutes. Operators additionally
perform a physical check of the reefer display twice per shift for units expected to
remain in the yard longer than twenty-four hours. Any reading outside the tolerance
band of plus or minus 0.5 degrees Celsius from set-point for more than one consecutive
reading is treated as a temperature deviation.

## 5. Temperature Deviation Response

When a temperature deviation is detected, the operator must: (1) physically inspect
the unit within thirty minutes, (2) check for power supply issues, door seal
integrity, and unit fault codes, (3) attempt a unit reset if a fault code is present
and the manufacturer's reset procedure permits it, and (4) escalate to the reefer
technician if the deviation persists after inspection or if no fault code is found.
Cargo type determines urgency: perishable cargo with narrow tolerance (such as
pharmaceuticals or certain produce) requires escalation to the reefer technician
immediately rather than waiting for the thirty-minute inspection window to close.

## 6. Power Failure Protocol

If a rack-wide power failure occurs, the duty operations manager is notified
immediately and affected reefer containers are prioritized for reconnection to backup
generator capacity in order of cargo sensitivity, as declared at gate-in. Containers
that cannot be reconnected within two hours must have their condition and elapsed
time logged, and the shipping line notified of the outage and expected cargo impact.

## 7. Pre-Departure Verification

Before a reefer container is loaded onto a vessel or released at the gate, the
operator confirms the unit is running at set-point, the power cable is disconnected
and stowed correctly (for vessel loading), and the final temperature reading is logged
against the container number as part of the terminal's cold chain record.
